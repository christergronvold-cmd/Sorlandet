THE WHOLE PROJECT - UPLOAD IT ALL
=================================

Add file -> Upload files -> select everything in this folder -> Commit.
Existing files are replaced. Nothing in here can damage your data: the two files
that hold the real positions (data/latest.json and data/track.json) are deliberately
NOT in this package, so there is nothing to be careful about.

Then two pastes, because GitHub will not accept a folder whose name starts with a dot.
For each one: Add file -> Create new file -> type the name -> paste the contents.

  .github/workflows/update.yml     <- from workflow/update.yml    (replaces the old one:
                                      open the existing file, pencil icon, select all, paste)
  .github/workflows/backfill.yml   <- from workflow/backfill.yml  (new file)

Secrets, Settings -> Secrets and variables -> Actions:

  AISSTREAM_API_KEY   already there
  BW_CLIENT_ID        christer.gronvold@gmail.com:Sorlandet     <- plain, not urlencoded
  BW_CLIENT_SECRET    the secret from My clients at barentswatch.no

Finally:

  Actions -> Update position -> Run workflow          (listens 55 minutes, dense track)
  Actions -> Backfill from BarentsWatch -> days 14    (fills in the last two weeks)

WHAT IS IN HERE
---------------
index.html            the page: map, wind and wave layers with a time slider, position,
                      voyage plan, on-board clock and sun, progress, ship's log,
                      day-by-day charts, share card with QR
data/ports.json       the 2026-2027 voyage plan with sailing waypoints, so the route
                      does not cut across land
scripts/update.py     listens 55 minutes an hour, keeps every position, thins old track,
                      fetches weather, wind and wave grids, sun and moon, daily history
scripts/backfill_barentswatch.py   dense historic AIS for Norwegian waters, 14 days
scripts/make_qr.py    regenerates share-qr.svg if the address ever changes
scripts/seed_demo.py  sample data for previewing the page locally
vendor/leaflet/       the map library, local so the page needs no CDN
share-qr.svg          QR code for https://christergronvold-cmd.github.io/Sorlandet/
README.md             the full documentation
